# Datasets

The benchmark splits are **not** committed to this repository. Download them and
place each dataset here as tab-separated `head<TAB>relation<TAB>tail` files:

```
kg/CoDEx-S/{train,valid,test}.txt
kg/CoDEx-M/{train,valid,test}.txt
kg/FB15k-237/{train,valid,test}.txt
```

Sources:
- CoDEx-S, CoDEx-M: https://github.com/tsafavi/codex
- FB15k-237: https://www.microsoft.com/en-us/download/details.aspx?id=52312
